# 旧版工作区产物

这里保存的是严格 PCAP/TCP/TLS/X.509 解析器和来源分组划分启用之前生成的工作区产物，共 54 个文件、2,221,005,267 字节（约 2.22 GB）。

这些文件缺少当前要求的 `feature_schema_version`、`group_id` 或 `split`，只用于历史追溯，不能作为当前训练流水线的输入。当前流水线从 `data/developer/datasets/prepared/` 重新提取，并在 `data/developer/workspace/` 生成新产物。

本目录下的 CSV、JSONL、图片和历史报告均为本机归档，不提交 Git；只跟踪本说明文件。
